## 👋 Bienvenue

L'organisation GitHub de l'UR CFTC Bretagne est l'espace de collaboration dédié aux projets numériques au service des structures et des responsables syndicaux bretons.

Les projets naissent des besoins exprimés par :

- les Unions Départementales ;
- les Unions Locales ;
- les syndicats professionnels ;
- les sections syndicales ;
- les élus CSE ;
- les délégués syndicaux ;
- les mandatés ;
- les responsables régionaux.

---

## 🎯 Notre méthode

Tous les projets suivent :

### SMART

- Spécifique
- Mesurable
- Atteignable
- Réaliste
- Temporel

### RACI

- Responsible
- Accountable
- Consulted
- Informed

## 💡 Proposer un projet

Une idée ?

➡️ Ouvrez une **Issue "Demande de projet"**.

Chaque proposition est analysée selon :

- son utilité ;
- son impact ;
- sa faisabilité ;
- son coût ;
- sa cohérence avec les orientations régionales.
