## 👋 Bienvenue

Cet espace GitHub regroupe les projets numériques portés par l'**Union Régionale CFTC Bretagne**.

L'objectif n'est pas de développer de la technologie pour la technologie, mais de répondre à des besoins concrets exprimés par :

- les Unions Départementales ;
- les Unions Locales ;
- les syndicats professionnels ;
- les sections syndicales ;
- les élus CSE ;
- les délégués syndicaux ;
- les représentants de proximité ;
- les mandatés dans les organismes paritaires et institutionnels ;
- les responsables syndicaux régionaux et départementaux.

Chaque projet vise à renforcer l'efficacité de l'action syndicale et à faciliter le travail des militants.

---

## 🎯 Notre démarche

Les projets sont construits à partir des besoins du terrain.

Nous cherchons à :

- simplifier l'organisation syndicale ;
- améliorer le partage des informations ;
- valoriser les expertises des militants ;
- développer de nouveaux services aux adhérents ;
- faciliter l'exercice des mandats ;
- expérimenter les usages de l'intelligence artificielle dans un cadre éthique et responsable.

## 📋 Gouvernance des projets

Tous les projets suivent une méthodologie basée sur les approches **SMART** et **RACI**.

### 🎯 Méthode SMART

Chaque demande de projet doit être :

| Critère | Description |
|----------|-------------|
| Spécifique | Le besoin est clairement défini |
| Mesurable | Les résultats attendus sont identifiés |
| Atteignable | Les moyens existent pour le réaliser |
| Réaliste | Le projet répond à un besoin concret |
| Temporel | Une échéance est fixée |

### 👥 Méthode RACI

Chaque projet définit clairement les responsabilités.

| Rôle | Description |
|--------|-------------|
| Responsible | Réalise le projet |
| Accountable | Porte la responsabilité finale |
| Consulted | Apporte son expertise |
| Informed | Est tenu informé |

## 🤝 Contribuer

Chaque besoin doit être déclaré via une **Issue GitHub**.

Les demandes sont étudiées selon :

- leur utilité pour les structures ;
- leur impact syndical ;
- leur faisabilité ;
- leur coût ;
- leur cohérence avec les orientations de l'UR CFTC Bretagne.

### Labels utilisés

| Label | Signification |
|---------|---------------|
| demande | Projet soumis |
| analyse | Étude en cours |
| validé | Projet accepté |
| refusé | Projet rejeté |
| à financer | Recherche de financement |
| en développement | Réalisation en cours |
| en test | Expérimentation |
| déployé | Disponible pour les structures |
